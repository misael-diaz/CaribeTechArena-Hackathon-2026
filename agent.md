# Agent Guidelines & Conventions

## 1. Naming Convention for Tests and Temporary Scripts
From now on, any test script, temporary debugging file, or utility script created by the AI agent **must** use the `agent_` prefix.

**Examples:**
- `agent_test_ai.py`
- `agent_verify_db.py`
- `agent_run_sim.py`

**Purpose:**
This ensures that all files generated by the agent for testing purposes are easily identifiable and do not get mixed up with the core application codebase or standard unit tests (`tests.py`). This also aligns with `.gitignore` rules if we decide to ignore them globally.
